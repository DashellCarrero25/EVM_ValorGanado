## ADDED Requirements

### Requirement: Documentación del proceso de desarrollo
El sistema SHALL incluir un archivo AI_PROCESS.md en el repositorio con prompts, decisiones, reflexiones y validaciones del proceso de desarrollo asistido por IA.

#### Scenario: Existencia de AI_PROCESS.md
- **WHEN** se revisa el repositorio
- **THEN** el archivo AI_PROCESS.md está presente y actualizado según los lineamientos
