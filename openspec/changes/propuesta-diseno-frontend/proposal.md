## Why

Un diseño visual claro y accesible es fundamental para que los usuarios comprendan rápidamente el estado de sus proyectos y actividades. Definir lineamientos de color y contraste desde el inicio asegura coherencia, accesibilidad y una experiencia de usuario profesional.

## What Changes

- Definición de paleta de colores base para el frontend.
- Lineamientos de contraste y accesibilidad para textos y elementos clave.
- Especificación de estilos para headers, backgrounds, alertas y tipografía.
- Propuesta visual para alertas y estados críticos.

## Capabilities
